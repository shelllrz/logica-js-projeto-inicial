# Lógica de Programação com JavaScript

Este repositório contém exercícios e exemplos desenvolvidos durante minhas aulas práticas de lógica de programação utilizando JavaScript.

## Conteúdos abordados
- Variáveis (let)
- Estruturas condicionais (if / else)
- Entrada de dados com prompt
- Saída de dados com alert

## Objetivo
Registrar minha evolução inicial em lógica de programação e boas práticas de código.
